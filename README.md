# Трекер Расходов

Учебное консольное приложение на Python для учёта личных расходов.

Проект позволяет добавлять расходы, просматривать их, считать общую сумму и получать статистику по категориям.

## Возможности

- добавление расходов;
- проверка корректности введённой суммы;
- просмотр всех расходов;
- подсчёт общей суммы;
- поиск расходов по категории;
- поиск без учёта регистра;
- статистика по категориям;
- обработка неправильного пункта меню.

## Технологии

- Python 3;
- стандартная библиотека `decimal`;
- списки и словари;
- функции;
- циклы;
- обработка исключений.

Сторонние библиотеки не используются.

## Хранение данных

Расходы хранятся в памяти во время работы программы.

После завершения программы данные удаляются.

## Структура расхода

Каждый расход содержит:

- название;
- сумму;
- категорию.

## Запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/taganrogec56-del/expense_tracker--SIMPLE.git
```

Перейдите в папку проекта:

```bash
cd expense_tracker--SIMPLE
```

Запустите приложение:

```bash
python main.py
```

## Пример работы

```text
=== Трекер Расходов ===

1. Добавить расход
2. Показать все расходы
3. Показать общую сумму расходов
4. Показать расходы по категории
5. Показать статистику по категориям
0. Выход

Выберите пункт: 1

Введите название: Продукты
Введите сумму: 1250
Введите категорию: Еда
Расход добавлен.

Выберите пункт: 1

Введите название: Такси
Введите сумму: 450
Введите категорию: Транспорт
Расход добавлен.

Выберите пункт: 2

=== Все расходы ===

1. Продукты — 1250.00 руб. — Еда
2. Такси — 450.00 руб. — Транспорт

Выберите пункт: 3

Общая сумма расходов: 1700.00 руб.

Выберите пункт: 5

=== Статистика ===

Еда: 1250.00 руб.
Транспорт: 450.00 руб.
```
